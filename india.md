- Project Type: Browser Trivia Game
- Team: Hayden Knight
- User Story: As a Brother and Marvel fan, I want to make a higher or lower power level game per request of my   brother, so he can test his marvel knowledge.
  Target Audience: My Little Brother

 # 💡 WHY -- Problem + Value
 
## Problem and Oppurtunity
- I am trying to create a replayable game for my little brother or anyone who is a Marvel fan for a fun way to   learn more about your favorite characters.

## Value Proposition
- This should exist because it is a fun game but can also be used as a marketing strategy for Marvel             movies/comics
- For my brother, my application is a fun game because it is replayable and quick form.

# WHAT ALREADY EXIST -- landscape

## Higher or Lower Game [Higher or Lower](https://www.higherorlowergame.com/)
- What is good?: Simple, gameplay, streak based scoring, mobile interface.
- What is missing?: The experience is over many topics not narrowed down to one people may enjoy more.
- What functionality matters?: Two characters, higher or lower buttons, score tracking.
- What can I borrow/avoid?: Borrow the simple interface and streak system; avoid making the game overly       complicated.
- Why build another?: My app focuses on just marvel power levels while this one is a broad category.
## Marvel Database -- Power Grid [Marvel Database](https://marvel.fandom.com/wiki/Power_Grid)
- What is good?: Provides the power scaling that will be used for the app.
- What is missing?: There is no game aspect just the power levels.
- What functionality matters?: Consistent character attributes and ratings.
- What can I borrow/avoid?: I can borrow the scaling for reference but avoid the random attributes and        create a simple scaling metric.
- Why build another?: A game will make this power level system easier to learn, and fun instead of just       being there to look at.
## Official Marvel Character Profiles [Marvel Characters](https://www.marvel.com/characters)
- What is good?: Provides official character descriptions and information.
- What is missing?: There is no game aspect just the character cards.
- What functionality matters?: Official information about the characters that will be used in the game.
- What can I borrow/avoid?: I can borrow the official information about the characters while I avoid making   it seem like these are official ratings from Marvels website.
- Why build another?: This will take the official characters and make comparsion to correctly power scale     them.
